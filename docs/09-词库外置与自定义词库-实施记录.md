# 开发记录 · 词库外置与自定义词库

日期：2026-09-12 · 对应 README 状态清单「词库外置与自定义词库」· 计划见
[08-词库外置与自定义词库-开发计划.md](./08-词库外置与自定义词库-开发计划.md)（按推荐决策 D1–D5 实施）。

## 1. 背景与决策

词典层数据（228 条整词映射 + 8 条上下文规则）原硬编码在 `src/proofread-dict.ts`
字面量里：更新词库要改 TS 源码，且用户无法补充自己领域的错词。计划评审定案：

- **D1** 词库 `data/zh-wrong-phrases.txt`（行式 `错词 => 正词`）+ 规则
  `data/zh-context-rules.json`（pattern/flags/fix 模板/reason）；
- **D2** `scripts/gen-dict.mjs` 构建前生成 `src/proofread-dict-data.generated.ts`
  并提交入库，CI 用 `gendict + git diff --exit-code` 守卫同步；
- **D3** 用户词库仅整词映射（不开放正则，规避 ReDoS 与转义风险）；
- **D4** UI 入口放 v5.1 设置卡片底部，独立区块；
- **D5** `错词 => 错词` 自映射 = 禁用内置词。

## 2. 实现

### 词库外置（M1）

- **数据文件**：由一次性脚本从原 TS 字面量机械提取（零抄写错误），228 词 + 8 规则，
  迁移后即删除脚本。README 原「约 150 条」说法顺带修正为实际值。
- **生成器 `scripts/gen-dict.mjs`**：构建期 fail-fast 校验（缺 `=>`、空白、自映射、
  重复错词、坏正则、flags 缺 `g`、fix 模板 `$N` 组号越界），生成零依赖纯数据模块
  （词表 + `RegExp` 字面量 + 替换模板），正则字面量经 `new RegExp(...).toString()`
  输出天然转义。解析/校验/生成函数导出供单测（main guard：`import.meta.url` 比对
  `argv[1]`，import 不触发副作用）。
- **`src/proofread-dict.ts` 重构**：数据移出后只留类型/解析/合并/扫描纯逻辑：
  - `applyTemplate(tpl, m)`——`$1/$2` 模板替换（未参与匹配的可选组 → 空串），
    承接原 8 条规则里 `(m) => \`必须${m[1] ?? ''}${m[2]}\`` 的函数语义；
  - `parseDictText`——行式文本解析（容错收集错误行，内置与用户词库同语法；
    运行期版接受自映射，构建期版禁止——自映射是用户「禁用」语义）；
  - `mergeDicts` / `scanWithDict`——核心扫描参数化；`scanLocalTypos` 退化为内置
    词库薄封装，host 兜底路径与既有测试零改动（`WRONG_PHRASES` 经 re-export 保持
    兼容）。
- **接线坑**：node 原生跑 `.ts`（type stripping）不把 `.js` 说明符重写到 `.ts`
  文件（tsdown 会），测试直接 import 源文件时报 `ERR_MODULE_NOT_FOUND`——内部
  依赖改用 `.ts` 后缀 + tsconfig 开 `allowImportingTsExtensions`。
- **CI**：`ci.yml` paths 补 `data/**`、`scripts/**`；新增 Dict sync guard 步骤
  （生成物漂移即红）。

### 用户词库（M2）

- `src/user-dict.ts`：localStorage 封装（key `dsh-input-assist:user-dict:v1`，**存
  行式原始文本**——与编辑框一一对应、复制粘贴即导入导出），读写全 try/catch，
  隐私模式/配额满/无 storage 一律降级为「无词库」。
- `src/client.ts` 词典层接线：200ms 防抖回调改为
  `scanWithUserDict(draft, loadUserDictText(dictStorage()))`——每轮现读现解析
  （千行 <1ms，不做缓存）。`rescanDict()` 供保存后立即重扫：作废在途防抖、复位
  会话级 dismiss，但保留逐条「标记正确」（用户明确意图，词库变化不翻案）。

### 设置卡片区块（M3）

- `settings-form.ts` 增 `checkUserDictText`（行式语法错误带行号 + 错词 ≤16 字 +
  词条 ≤2000）；`client.ts` 卡片 body 内 proofread 组之后渲染「自定义词库（仅本
  浏览器）」区块：等宽 textarea、条数统计、非法行红字列表、独立「保存/放弃」
  （**与上方配置暂存流隔离**——存储目标 localStorage vs settings.yaml）；保存成功
  即 `rescanDict()`；写失败降级提示（role=status）。i18n 中英双语。
